세명전기 웹사이트 (분리형)

[구조]
  index.html      ← 메인 페이지 (가벼움, 그대로 편집 가능)
  images/         ← 사진 폴더

[여는 법]
  - VS Code에서 이 폴더를 열고 index.html을 Live Server로 실행하거나
  - index.html 파일을 브라우저로 바로 드래그해서 열면 됩니다.

[수정 안내]
  - 회사명/전화번호: index.html 에서 "세명전기", "1588-0000" 검색 후 교체
  - 실적 숫자: data-to 값 수정
  - 사진 교체: images/ 폴더의 파일을 같은 이름으로 바꿔 넣으면 됩니다.
